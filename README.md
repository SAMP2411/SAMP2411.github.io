## Project archive

The detailed engineering case-study page is available at **[samp2411.github.io/projects.html](https://samp2411.github.io/projects.html)**.

It currently documents:

- **TurtleBot3 — Autonomous Navigation, SLAM & Localization**: ROS2/Nav2, TF/odometry, SLAM, AMCL, planner comparison and simulation-to-real validation.
- **UR10 Manipulator — Kinematics, Trajectory Planning & Control**: MATLAB/Simulink, ROS, forward/inverse kinematics, DLS and trajectory validation.
- **IIoT Anomaly Detector — Edge-to-Cloud Monitoring**: Python, MQTT, Isolation Forest and Plotly. [Repository](https://github.com/SAMP2411/AI-Based-IIoT-Anomaly-Detector)

- **RST Hackathon — Vision-Guided Robot Arm Challenge**: computer vision, target tracking, coordinate transforms and robot strategy; third place in October 2025.
- **J&J MedTech — Robotics & Controls Troubleshooting**: completed Forage job simulation covering Python control-code review, command timing, iterative testing and technical documentation.
- **SO-101 Robot Arm — Zero-Shot, Few-Shot & In-Context Learning for Pick-and-Place**: ongoing robot-learning project, explicitly marked as in development.
