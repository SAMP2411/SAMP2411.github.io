Completed Industrial AI Project

IIoT Anomaly Detector

Built an edge-to-cloud style monitoring pipeline that streams sensor telemetry over MQTT, applies unsupervised anomaly detection and visualizes operating behavior.

Python · MQTT · Isolation Forest · scikit-learn · Plotly · Streaming Telemetry

Engineering Challenge

Industrial telemetry needs to be processed continuously rather than only in an offline notebook, while anomaly detection must remain lightweight enough for a practical streaming pipeline.

Implementation

Created MQTT publisher/subscriber components for simulated industrial sensor values such as temperature, vibration and current. The subscriber processed incoming data, applied an Isolation Forest model and surfaced anomalous points in a Plotly-based monitoring view.

System Architecture

Sensor/data generator → MQTT publisher → broker/topic → Python subscriber → preprocessing → Isolation Forest inference → anomaly log → Plotly dashboard.

Validation & Debugging

The documented implementation processed more than 5,000 simulated sensor points and reported end-to-end pipeline latency below about 300 ms. Peak-like injected conditions were used to inspect whether the detector reacted as expected.

Engineering Decisions

Isolation Forest was chosen because labelled failure data was not available. The project therefore treats model output as anomaly detection, not as a claim of labelled fault-classification accuracy.
